# P7.3 · Spectral Forge Navigator – region resize and preview scan

**Patch 11** on top of the P7.2 patch chain. No app source tree, no HTML bundle, and no node_modules are bundled.

## User intent / behaviour
- The violet selection in the Carrier Navigator now has **invisible left/right resize hit-zones** (~9 screen px). Hover changes to horizontal `ew-resize`; dragging modifies only that region, **not** the cyan Navigator viewport.
- Clicking a boundary without dragging retains the selection (does not seek/clear).
- Normal drag on an unselected part of the Navigator still creates a region; Alt+Drag and cyan zoom handles retain the earlier semantics.
- Region Preview (the small ▶ next to Save as Sample) renders the chosen Forge listening mode, then displays a **purple-pink playhead** across that exact selected region for the length of the actual sliced PCM buffer.
- The animated scan uses CSS transforms (no extra RAF loop, new AudioContext, timer or oscillator).
- Selection edit and preview stop cancel the scan, and Ended clears its state. No change to RFL, Drone, Keyboard, Bass, Power, or Forge main transport.
- Existing toolbar label changes to `Violet trim · Cyan zoom` with full English title.
- To the **left** of the small ▶, a **102 × 25 px** name field and a left-aligned `Sample Name:` caption match the typography/vertical alignment of `Project Name:`; Preview and Save retain their coordinates.
- The title is passed to actual Sample Database registration. Blank title retains existing autogenerated naming; typed names are sanitized. Typing never triggers global keyboard shortcuts.

## Limitations
- The browser animation test drives preview state with a **test-only accessor** inserted into the in-memory page HTML. It does not prove audible PCM playback with a populated Forge drawing; actual audio audition in Opera remains a human acceptance check.
- The scan is a visual approximation tied to PCM playback duration and CSS animation startup; it does not read the audio rendering clock each frame, deliberately avoiding live thread overhead.
- `npm run test:merge` retains the earlier known historical Nodal preservation-hash conflict from patch 00. It was not relaxed.
