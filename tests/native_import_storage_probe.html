XenSonar – Native Browser Storage Probe

Dieser eigenständige Test verwendet nur die separate IndexedDB xensonar-import-milestone-probe-v1 und den eigenen LocalStorage-Schlüssel xensonar.import-probe.v1. Er verändert keine XenSonar-Bibliotheken, Audiodaten oder Projekte.

Im Zielbrowser (Opera/Firefox) als lokale HTML öffnen, „Tests durchführen“ anklicken und das Ergebnis sichern. Die Tests prüfen Browser-Speichergrundlagen, nicht den vollständigen XenSonar-Workspace-Importer.

Noch nicht ausgeführt.

Eine bestandene Storage-Probe allein ist keine Freigabe des gesamten Import-Systems. Die echten Merge-/Replace-/Differential- und Wiederanlauffälle müssen separat mit Testarchiven durchlaufen.
