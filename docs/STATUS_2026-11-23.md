## Fehler „Room error isolated … reading 'koe'“
Nicht reproduzierbar: `index.html` jedes 3. Commits seit `7f795ec` bis zum Kopf, per `file://` in Chromium, Raumwechsel, Art Installation, Gate offen, Reload: kein Fehler.
Wahrscheinliche Ursache (nicht bewiesen): `__xenLoadDeferred("nodal")` liefert `undefined`, wenn der Raum-Payload leer ist. Der Lazy-Loader leert `<script id="xen-room-nodal">` nach dem Laden (`el.textContent=''`). Eine per „Seite speichern“ aus dem Browser gesicherte Datei enthaelt den **leeren** Raum, `eval('')` ergibt `undefined`, daraus `reading 'koe'`. Die ausgelieferte Datei ist der Build aus dem Repo (`index.html` im Zweig), nicht ein gespeicherter DOM-Stand.
